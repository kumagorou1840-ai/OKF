## 大家実務：修繕・費用負担の判断基準

| 原因・対象 | 原則的な負担 |
| :--- | :--- |
| 通常の経年劣化・設備そのものの不具合 | 大家 |
| 共用部・建物本体の設備・配管 | 大家 |
| 店子の過失・不適切な使用方法 | 店子 |
| 水抜き忘れ等による凍結・破損 | 店子（過失状況により確認） |
| 事前連絡なく店子が手配した臨時修理 | 原則店子（緊急時除き大家事前確認が必要） |
| 大家側の設備不良に起因する被害 | 大家 |
| 原因不明・双方に責任がある場合 | 調査結果を踏まえ協議 |

### 運用ルール
- 費用負担は原因調査前に即断しない
- 緊急時は被害拡大防止を最優先し、直ちに応急処置を行う
- 通常の修繕は事前に見積金額と負担区分を明示する
- 高額修理・保険対象の修繕は書面または記録に残して承認を得る
- 最終的な対応・負担履歴をノートに保存する
