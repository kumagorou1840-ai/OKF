# エージェント推論フレームワーク比較サーベイ

## 1. 主要アプローチ比較マトリクス
| アプローチ系統 | 代表的手法 | コアメカニズム | メリット | 主な課題 |
| :--- | :--- | :--- | :--- | :--- |
| **逐次実行型** | ReAct | 思考(Thought)と行動(Action)の交互反復 | 実装が平易、即時復帰 | 長期タスクでの文脈喪失 |
| **ツリー探索型** | ToT / RAP | 木・グラフ展開と探索（DFS/MCTS） | 高度な推論、バックトラック可能 | レイテンシ・計算コスト大 |
| **自己反省型** | Reflexion | 過去試行の自己言語フィードバック | 追加学習なしで成功率改善 | 誤った前提の固定化リスク |
| **協調型** | MetaGPT | 役割分担(SOP)による複数対話 | 分業・レビューによる高精度化 | 会話発散・トークン肥大 |

`agy` のコンテキスト消費を最小化し、探索・構造化・ファイル出力を自律完結させる実践的なファイル分割設計です。

### ディレクトリ構造

Plaintext

```
research-vault-agent/
├── .antigravity/
│   ├── settings.json              # モデル選択・トークン上限・タイムアウト設定
│   ├── mcp_config.json            # fetch, filesystem などのMCP接続定義
│   └── rules.md                   # エージェント行動規範（破壊的変更の禁止、命名規則）
├── prompts/
│   ├── 01_search_plan.md          # 検索クエリ設計・仮説生成用プロンプト
│   └── 02_summarize_note.md       # Obsidian用Markdown（Frontmatter付き）整形プロンプト
├── tools/
│   ├── arxiv_fetcher.py           # 論文・Webテキスト取得スクリプト
│   └── vault_writer.py            # Obsidian保管庫へのファイル書き込み・重複検知
├── workspace/
│   ├── queue.json                 # 調査対象キュー・進捗ステートマシン
│   └── cache/                     # 生データ・ダウンロード一時保管
└── run_pipeline.ps1               # agyコマンドを一括キックするバッチ実行スクリプト
```

PowerShellを使って、フォルダの作成から各設定ファイルの配置までを段階的に構築します。

まずは **ステップ1（フォルダと設定ファイルの自動生成）** から進めます。

### ステップ1: フォルダ構造と設定ファイルの作成

PowerShellを開き、以下のコマンドを貼り付けて **Enter** を押してください。 （作業用フォルダ `C:\Users\PC_User\research-vault-agent` を作成し、必要な全ファイルと初期コードを一括配置します）

PowerShell

```
# 1. ワークスペースルートの作成
$baseDir = "C:\Users\PC_User\research-vault-agent"
New-Item -ItemType Directory -Force -Path "$baseDir\.antigravity"
New-Item -ItemType Directory -Force -Path "$baseDir\prompts"
New-Item -ItemType Directory -Force -Path "$baseDir\tools"
New-Item -ItemType Directory -Force -Path "$baseDir\workspace\cache"

# 2. .antigravity/rules.md の生成
@'
# 実行制約・ルール
1. 出力ファイルはすべてUTF-8（BOMなし）で保存すること。
2. ObsidianノートのFrontmatterには必ず id, tags, created を含めること。
3. 既存のファイルを上書きする際は、必ず tools/vault_writer.py --diff を通して差分確認を行うこと。
4. 1ステップで処理が完了しない場合は、進捗を workspace/queue.json に記録して一度停止すること。
'@ | Set-Content -Path "$baseDir\.antigravity\rules.md" -Encoding UTF8

# 3. .antigravity/mcp_config.json の生成
@'
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "C:\\Users\\PC_User\\Documents\\Obsidian\\obsidian_1"]
    },
    "fetch": {
      "command": "uvx",
      "args": ["mcp-server-fetch"]
    }
  }
}
'@ | Set-Content -Path "$baseDir\.antigravity\mcp_config.json" -Encoding UTF8

# 4. workspace/queue.json の初期状態生成
@'
{
  "session_id": "session-init",
  "topic": "エージェント推論フレームワーク",
  "current_step": "ready",
  "steps": {
    "planning": "pending",
    "fetching": "pending",
    "structuring": "pending",
    "vault_sync": "pending"
  },
  "collected_count": 0
}
'@ | Set-Content -Path "$baseDir\workspace\queue.json" -Encoding UTF8

# 5. prompts/02_summarize_note.md の生成
@'
---
role: research_structurer
---
以下の入力データを元に、Obsidian用のナレッジノートをMarkdown形式で作成してください。
必ずYAML Frontmatter（id, tags, created, status）を付与し、要約・キー概念・既存ノートへの接続リンク（[[...]]）を明記してください。
'@ | Set-Content -Path "$baseDir\prompts\02_summarize_note.md" -Encoding UTF8

# 完了確認
Get-ChildItem -Path $baseDir -Recurse | Select-Object FullName
```

上記を実行すると、末尾に作成されたファイル一覧が表示されます。 エラーなく完了したらお知らせください。次のステップ（Pythonスクリプトおよび実行バッチの配置）へ進みます。

######################################################################################

すべてのファイルとフォルダが正常に作成されています。

続いて **ステップ2（ツールスクリプトと実行パイプラインの配置）** を行います。

PowerShellに以下のコマンドを貼り付けて **Enter** を押してください。

PowerShell

```
$baseDir = "C:\Users\PC_User\research-vault-agent"

# 1. tools/vault_writer.py（Obsidianへの書き込み支援スクリプト）の生成
@'
import sys
import os
from pathlib import Path

def write_note(target_path, content):
    p = Path(target_path)
    p.parent.mkdir(parents=True, exist_ok=True)
    with open(p, "w", encoding="utf-8") as f:
        f.write(content)
    print(f"[SUCCESS] Wrote note to: {target_path}")

if __name__ == "__main__":
    if len(sys.argv) > 2:
        write_note(sys.argv[1], sys.argv[2])
    else:
        print("[INFO] vault_writer initialized.")
'@ | Set-Content -Path "$baseDir\tools\vault_writer.py" -Encoding UTF8

# 2. run_pipeline.ps1（全体実行用スクリプト）の生成
@'
$baseDir = "C:\Users\PC_User\research-vault-agent"
Set-Location $baseDir

Write-Host "=== AGY Research Vault Agent Pipeline ===" -ForegroundColor Cyan

# キュー状態の確認
$queue = Get-Content .\workspace\queue.json | ConvertFrom-Json
Write-Host "Current Topic : $($queue.topic)" -ForegroundColor Yellow
Write-Host "Current Step  : $($queue.current_step)" -ForegroundColor Yellow

# スクリプト初期化テスト
python .\tools\vault_writer.py

Write-Host "`nセットアップおよび疎通確認が正常に完了しました。" -ForegroundColor Green
'@ | Set-Content -Path "$baseDir\run_pipeline.ps1" -Encoding UTF8

# 3. 動作確認テストの実行
powershell -ExecutionPolicy Bypass -File "$baseDir\run_pipeline.ps1"
```

実行後、緑色の文字で「セットアップおよび疎通確認が正常に完了しました。」と表示されるかご確認ください。
