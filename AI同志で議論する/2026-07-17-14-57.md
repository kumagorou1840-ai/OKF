# 🚀 Antigravity (LLM as an OS) が自律実行できる代表的能力 50選

> [!abstract] 概要
> Antigravity は単なるチャットAIではなく、ファイルシステム、仮想環境、ネットワーク、視覚言語モデル（VLM）、コード実行環境のすべてを掌握し、人間のように自律的に思考・試行錯誤しながら複雑なタスクを達成する **「LLM as an OS（AIオペレーティングシステム）」** です。
> 本ノートでは、Antigravity が自律的に実行できる代表的な50の機能と実例をまとめています。

---

## パート1：基本・応用能力 20選 (1〜20)

### 🖥️ 1. クロスアプリケーション・オートメーション（アプリ間自動連携）
- **できること**: 独立した複数のソフトウェアやWebサービスを、人間のように横断して操作する。
- **実例**: ブラウザでポータルサイトから物件情報をスクレイピングし、デスクトップのExcelマクロを起動してデータを流し込み、完了後にSlackで報告する一連の作業を全自動化。

### 📊 2. 自己修正デバッグ（ループ検証）
- **できること**: コードを実行し、エラーが発生したらログを自ら解読して原因を特定し、修正・再実行を成功するまで繰り返す。
- **実例**: Pythonスクリプトの実行時に「ライブラリのバージョン競合エラー」を検知した際、自動で内部の仮想環境（`venv`）のパッケージを調整して再実行、正常終了させる。

### 🌐 3. VLM（視覚言語モデル）による画面・UIの視覚的検証
- **できること**: コードテキストだけでなく、レンダリングされた画面そのものを「視覚的に認識」して意図通りかチェックする。
- **実例**: 自動生成した Plotly の 3D グラフ画面を視覚的にスキャンし、「指示通りにグラフが自動回転しているか」「指定したX軸とY軸の交点にピンポイントでマーカーがプロットされているか」を画像認識で確認。

### 📝 4. ゴール指向のタスクブレイクダウン（バックワード・チェーニング）
- **できること**: 抽象的な最終目的だけを渡すと、逆算して必要なタスクを自動で切り出し順序立てて実行する。
- **実例**: 「今月の損益分岐点をシミュレーションしたい」と指示すると、自動的に「①関連するMarkdownノートの検索 ➔ ②CSVデータの読み込み ➔ ③数式モデルの構築 ➔ ④検証」というタスクリストに分解して実行。

### 🗄️ 5. セマンティック・ファイルシステム管理（意味ベースの検索）
- **できること**: ファイル名や階層ではなく、ファイル内容の「意味・文脈」を理解して必要な情報を探し出す。
- **実例**: Obsidian 内の数千個の雑多なノートから、「過去に検証した不動産減価償却の数理モデルが書かれているメモ」を文脈検索で即座に特定。

### 🔄 6. ヒューマン・イン・ザ・ループ（動的な人間への承認要求）
- **できること**: 基本は自律動作しつつ、重要な法的判断やコスト発生の手前で自動停止し、人間に確認を求める。
- **実例**: 契約書のリーガルチェックと修正案作成を自動で進め、最終契約の直前に Mission Control にポップアップを出し、ユーザーの `[承認]` ボタン入力を待つ。

### 🛠️ 7. リアルタイム・サンドボックス環境の自動構築
- **できること**: タスク実行のためだけに、安全でクリーンな一時的開発環境（コンテナ）を裏で瞬時に立ち上げる。
- **実例**: 未知のオープンソースライブラリをテストする際、メインPC環境を汚さないよう隔離された Docker コンテナを自動起動して検証。

### 📄 8. ドキュメント駆動開発（仕様書からのコード自動生成・テスト）
- **できること**: 人間が書いた仕様書や設計メモ（Markdown等）を読み込み、コードとテストプログラムをセットで自動作成する。
- **実例**: Obsidian に書いた「在庫管理システムのテーブル定義メモ」から、AppSheet 用の CSV と、データ整合性をチェックする Python スクリプトを自動生成。

### 🔀 9. 動的な例外処理と代替案の実行（条件分岐の自動判断）
- **できること**: 予定していた手段が使えない場合、処理をストップさせずに「別の代替手段」を自分で考えて切り替える。
- **実例**: Webスクレイピングが相手サイトの仕様変更でブロックされた際、即座に「公式API経由」や「別の情報ソース」へ思考を切り替えてタスクを続行。

### 🧠 10. メモリ永続化と長期文脈の管理（コンテキスト管理）
- **できること**: 過去のセッションや別タスクで得た知見やユーザーの好みを、新しいタスクにも一貫して反映させる。
- **実例**: 数日前に作成した「3Dグラフのプロット設定」を記憶しており、新しいグラフ作成指示でも自動的に 3D 自動回転コードを組み込んで出力。

### 🎨 11. ダイナミック・UI/ウィジェットの即時生成
- **できること**: 静的なテキストだけでなく、人間がその場で操作・試行できるインタラクティブなプログラム（Widget）を画面上に生成。
- **実例**: 「不動産の投資回収期間シミュレータを作って」と頼むと、家賃や利回りのスライダーでリアルタイムにグラフが動く 2D/3D ウィジェットをその場で構築。

### 🔒 12. 自律的なセキュリティ＆コンプライアンス監査
- **できること**: 生成したコードやデータの中に、セキュリティリスクや個人情報漏洩、設定ミスがないかを事前にチェック。
- **実例**: Google Cloud（GCP）の環境構築スクリプト生成時、ユーザー権限の設定が外部公開状態になっていないかをデプロイ前に自動監査。

### 🕒 13. バックグラウンドでの非同期・長時間タスクの実行
- **できること**: 人間がPCを閉じている間や別作業中も、数時間に及ぶ重いリサーチやデータ処理をバックグラウンドで自律実行。
- **実例**: 「競合他社の過去5年分の決算データとプレスリリースを集めて財務・マーケティング両面から分析レポートを作成して」と指示し、放置しておくと完成レポートが生成される。

### 📈 14. 数理モデルへの実データフィッティング（自動最適化）
- **できること**: 数学的な理論式（線形代数や微分方程式等）に実ビジネスデータを流し込み、パラメータを自動調整。
- **実例**: 「いかにして問題を解くか」等の数理最適化アプローチを用い、過去の売上・在庫データから損益分岐点を最小化する最適発注タイミング（在庫最適化モデル）を計算・検証（参照: [[2026-07-17-16-35]]）。

### 🧪 15. A/Bテスト・複数パターンの同時並行検証
- **できること**: 1つの正解を出すだけでなく、複数のアプローチを並列生成し、パフォーマンスを自動比較テスト。
- **実例**: 「計算処理の高速化」において、NumPy ベクトル演算パターンと通常のループ処理パターンの2つのコードを並列実行し、速い方を自動採用。

### 📁 16. ナレッジベースの自動リファクタリング（ノートの整理）
- **できること**: 散らかったメモやノートを、構造化されたリンク関係やテンプレートに基づいて自動で整理・クリーニング。
- **実例**: Obsidian フォルダ内の雑多な「読書ログ」や「開発日記」をスキャンし、タグ付けの統一、リンク関係の補正、未整理ノートのカテゴリ分けを自動実行。

### 📡 17. ライブAPI連携とリアルタイム・モニタリング
- **できること**: 外部 API と常時接続し、特定のトリガー（数値の変化等）を検知したら自律的にタスクを起動。
- **実例**: 株価・金利・不動産オープンデータ API を定期監視し、設定した閾値を越えた瞬間に財務エージェントを起動して再計算・通知。

### 🔀 18. バージョン管理（Git）の完全自動ハンドリング
- **できること**: コード変更に伴うコミットメッセージ作成、ブランチ切り替え、コンフリクト（競合）解消を AI が判断して実行。
- **実例**: 複数人の変更による Git コンフリクトを検知し、お互いのロジックが壊れないよう自動マージしてコミット完了。

### 📖 19. 多言語・多ドメインのコンテキスト翻訳と要約
- **できること**: 専門的な技術文書（英語の数理論文など）を読み込み、別のドメイン（日本の不動産実務など）にローカライズして適用。
- **実例**: 海外の最新 AI エージェントの英語ドキュメントを読み込み、日本の Windows PC 環境で動くローカルスクリプトへ移植。

### 🛠️ 20. ツール自給自足（自己拡張能力）
- **できること**: 既存ツールで解決できない問題に直面した際、解決するための新しいミニツールを自作して使用。
- **実例**: 特殊なバイナリ形式のデータファイルを読み込むため、専用のカスタムパーサー（解析プログラム）をその場で自作してデータ抽出を完結。

## 🌐 パート2：高度・インフラ・発展能力 30選 (21〜50)

### ネットワーク・インフラ・セキュリティ領域

#### 21. ローカルLLM環境の自動クレンジング・リソース最適化
- **実例**: PCのストレージ容量が逼迫した際、PowerShell 経由で不要になった古いローカルモデル（例: `ollama rm gemma3`）を自律削除し容量を確保。

#### 22. APIキー・認証情報の安全なローテーションと環境変数移行
- **実例**: コード内に直接書き込まれたパスワードや API キーを検知し、`os.getenv` 参照に自動リファクタリングして `.env` ファイルへ安全に退避。

#### 23. ネットワークパケット・通信エラーの自動キャプチャと原因特定
- **実例**: 外部 API 通信で `403 Forbidden` エラーが発生した際、送信ヘッダーの User-Agent 不備を分析し、適切なヘッダーを付与して自動再接続。

#### 24. クラウドインフラ（IaaS）の設定不備の自動監査とワンクリック修正
- **実例**: GCP のストレージバケットが全体公開になっているのを検知し、権限を特定ユーザーのみに限定する修正スクリプトを自動適用。

### 📊 データサイエンス・数理モデリング領域

#### 25. 異種データソースの自動名寄せとスキーマ統合
- **実例**: 「物件名」と書かれた CSV と「マンション名」と書かれた Excel を自動で同一項目と判断（名寄せ）し、1つの統合シートを作成。

#### 26. 数理最適化モデルの動的チューニング（制約条件の自動調整）
- **実例**: 損益分岐点シミュレーションで「固定費の変動」が発生した際、SciPy コードの境界条件（Bounds）を自動で書き換えて最適発注量を再計算。

#### 27. 時系列データの異常検知とアラート原因の自動ドキュメント化
- **実例**: 経費データ内の突発的なスパイク（突出値）を検知し、関連領収書 CSV を検索して原因を特定した Markdown レポートを生成。

#### 28. テキストデータの感情分析（センチメント分析）と定性データの数値化
- **実例**: 1,000件のユーザーレビューを読み込み、ポジティブ・ネガティブ要素を分析して改善優先度付き Plotly グラフを出力。

### 💻 ソフトウェア開発・ツール構築領域

#### 29. ローカルエディタとAIエージェントの競合・上書き防止（ファイル保護）
- **実例**: 人間が手動編集中のメインコードを AI が勝手に上書きしないよう変更検知を行い、差分（Diff）の承認を人間に求める。

#### 30. 音声入力テキストの自動タイポ修正・文脈整形（文字起こし連携）
- **実例**: Amical 等の音声入力による誤変換や曖昧な発話から本来の意図を正確に解釈し、正しいプロンプト・コードへ補正して実行。

#### 31. テストカバレッジの自動計測と未テストルートの網羅
- **実例**: テスト実行後のカバレッジを測定し、分岐エラー処理の漏れを発見して自動的にモックテストデータを生成。

#### 32. データベースのER図（実体関連図）の自動生成とマイグレーション
- **実例**: DB テーブル構造を読み取って Mermaid 図を自動生成し、カラム追加に必要な安全なマイグレーション SQL を作成。

#### 33. レガシーコード（古い言語・記述）のモダンアーキテクチャへの自動変換
- **実例**: 古いスタイルの静的 Plotly グラフコードを、動的な 3D 自動回転アニメーションに対応した最新コードへリファクタリング。

### 📂 ナレッジマネジメント・知的生産領域

#### 34. 電子書籍や論文PDFからの「数式・ロジック」の自動抽出とコード化
- **実例**: 技術書の数式画像を VLM でスキャンし、数理モデルを理解して NumPy / SciPy アルゴリズムコードとして実装。

#### 35. Obsidianノート間の「隠れた関連性」の自動リンク提案
- **実例**: 新しい開発日記を書くと、過去の固有値分析メモと文脈が一致していることを検知し、双方向リンク `[[ノート名]]` を自動挿入。

#### 36. 読書ログからの「即実践タスクリスト」への自動変換
- **実例**: ビジネス書メモの「フェルミ推定」から「潜在市場規模を推定する Python スクリプト作成」というタスクを切り出して登録。

#### 37. 音声議事録からの「決定事項・宿題」の自動構造化マッピング
- **実例**: 会議の文字起こしから雑談を除外し、「決定事項」「担当者別の次回タスク」に構造化した Markdown 議事録を作成。

### 🏢 ビジネスオペレーション・不動産・法務領域

#### 38. 契約書の不利益条項（スニークイン条項）の自動検知
- **実例**: 契約書 PDF をスキャンし、一般条項から逸脱した「自社に著しく不利な特約」や曖昧な免責規定を法務エージェントが自動検知。

#### 39. 登記簿謄本（PDF）や公図の自動解析とデータ抽出
- **実例**: 登記簿 PDF から甲区（所有権）・乙区（抵当権）のデータを OCR / VLM 解析し、有効な債権額を自動計算して集計。

#### 40. 競合他社の価格変更・ポータルサイトの自動巡回モニタリング
- **実例**: 不動産ポータルを毎朝巡回し、競合物件の価格変更（例: 2,000万円 ➔ 1,850万円）を検知して収支モデルへの影響を自動再計算。

#### 41. 投資用不動産の「複数シナリオ（楽観・悲観・現実）」収支自動シミュレーション
- **実例**: 金利上昇や空室率変動などのリスクを組み合わせたモンテカルロシミュレーションを実行し、損益分岐点 3D グラフを出力。

#### 42. 行政のガイドライン・都市計画変更情報の自動要約と影響分析
- **実例**: 自治体の建蔽率規制緩和のニュースを検知し、所有物件の資産価値や再建築時メリットを自動試算。

#### 43. Webプロトタイプのビジュアル回帰テスト（見た目の崩れ検知）
- **実例**: アプリ更新前後の画面キャプチャを比べるVLM画像認識で、スマホ画面サイズでのボタン重なりやレイアウト崩れを検出。

#### 45. ユーザーの操作ログ（ヒートマップ風データ）からのUIボトルネック自動特定
- **実例**: アプリ入力画面での滞留ログから「入力項目の並び順」に課題があると特定し、UIカイゼン案を自動提示。

### 🔄 運用自動化・自己進化・メタ認知領域

#### 46. エージェント自身の「プロンプト（指示書）」の自動自己改善（セルフ・リファイン）
- **実例**: タスク実行に失敗した際、原因を自己分析し、次回以降の実行精度を上げるよう自らのシステムプロンプト・制約文を更新。

#### 47. 定期タスクのスケジュール（Cron）自律管理と実行タイミング最適化
- **実例**: PC の CPU 使用率やネットワーク混雑状況を考慮し、重いデータ集計処理を自動的に「深夜2時」にスケジューリングして実行。

#### 48. トークンコスト・課金状況のリアルタイム監視とモデル自動ダウングレード
- **実例**: 当月 API 利用額が上限に近づいた際、スペルチェック等の軽量タスクを安価なモデル（Flash等）へ自動変更して節約。

#### 49. 不明瞭な指示に対する「2択・3択の具体的選択肢」の自動生成
- **実例**: 「グラフを作って」という曖昧な指示に対し、「①3D散布図、②2D相関図、③時系列棒グラフ」の具体案を先回りして人間に提示。

#### 50. 完全自律型の「週報・月報・システム稼働ログ」のインテリジェント作成
- **実例**: 月末にエージェントの全活動・成果物・自動修正履歴・削減時間を自動集計し、グラフィカルな `monthly_report.md` を作成。
