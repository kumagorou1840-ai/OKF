# Book to Reality ワークフロー

本や専門書の知識を単なるインプット（読書体験）で終わらせず、現実の業務、経営、または開発プロジェクトへ直結させるための構造化フレームワーク。

## 1. 核心抽出（Extraction）
* **原則の特定**：書籍全体、または指定された章から、現実に応用可能なコア原則・メンタルモデルを最大3つに絞り込む。
* **抽象化と翻訳**：著者の文脈（時代・業界）から、ユーザーの現在のドメイン（不動産経営、システム開発、自動化ワークフロー等）へ概念を翻訳する。

## 2. ギャップ分析（Gap Analysis）
* **現状との乖離**：現在の業務やシステムの状態と、書籍が推奨する理想状態のギャップを明確にする。
* **ボトルネックの特定**：なぜこれまでそれができていなかったのか、構造的な原因（時間、知識、仕組みの欠如）を診断する。

## 3. 実装・アクション化（Action Plan）
抽象的なアドバイスを排し、すぐ実行できる具体的なタスクに落とし込む。
* **チェックリスト形式**：`[ ]` を用いた段階的な実行項目を作成する。
* **自動化・仕組み化**：単なる精神論ではなく、スクリプト、テンプレート、またはワークフローとして定着させられる形にする。

## 4. 出力フォーマット
出力時は以下の構成を厳守する：
1. **エグゼクティブサマリー**（3行で要約）
2. **コア原則の翻訳と適用先**（Markdown表形式）
3. **具体的なアクションプラン**（チェックリスト形式 `[ ]`）
4. **構造・要素診断**（核・質・特・欠・方・移・拡・新）
