# タスク指示: 業務・データ分析サマリー

## 目的
入力された業務データ（CSV / テーブル / ログデータ）を多角的に集計・解析し、意思決定に直結するサマリーレポートおよびPlotlyダッシュボード用可視化コードを自動生成する。

## 前提条件・入力
- 入力データ形式: CSV, Pandas DataFrame, または JSON
- 可視化ライブラリ: Plotly / Dash

## 実行ステップ
1. **データ受領・前処理**: 欠損値補完、異常値検出、型定義の正規化を行う。
2. **基本統計量・KPI算出**: 合計・平均・中央値・標準偏差および主要KPI（成長率、構成比など）を算出。
3. **要因分析・インサイト抽出**: 主要な変動要因、ボトルネック、相関傾向を3〜5点に要約。
4. **ダッシュボード可視化（Plotly）**:
   - 4象限マトリクスまたは時系列トレンド＋構成比グラフのPlotlyコードを生成。
   - ダークテーマ・インタラクティブUIに適したレイアウトで出力。
5. **ネクストアクション提言**: 分析結果に基づく具体的な打ち手を箇条書きで提示。

## 出力フォーマット
1. エグゼクティブサマリー（要約）
2. 主要KPIテーブル
3. Plotly可視化コード（Python）
4. アクションプラン
