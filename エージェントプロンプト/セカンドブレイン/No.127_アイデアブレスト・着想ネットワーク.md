### 1. インプット要件定義

断片的な思いつき（Fleeting Notes）からプロジェクト構想まで、着想の鮮度を落とさずObsidianへ流し込むための受け入れ要件です。

- **入力経路（インテーク）の統一**
    
    - 音声入力（外出先・作業中の音声文字起こしテキスト）
        
    - テキストメモ（Obsidian Daily Note、クイックキャプチャ）
        
    - 外部インスピレーション（Web記事、書籍ハイライト、顧客との対話ログ）
        
- **必須インプット要素（3要素）**
    
    - **Core Insight（核となる発想）**: 何が思い浮かんだのかを1行で表現した文章。
        
    - **Trigger / Context（着想のきっかけ）**: どの事象・既存ノートから触発されたか（課題感、異分野の類似例など）。
        
    - **Target Domain（適用対象領域）**: どの業務・事業・プロジェクトに活かせるアイデアか。
        
- **受け入れ基準（Definition of Ready）**
    
    - 1ノート1アイデア（アトミック性）が保たれていること。
        
    - 既存のハブ（MOC）または関連する概念ノートへの内部リンクが最低1つ指定されていること。
        

### 2. メタデータ設計（YAML Frontmatter）

着想の成熟度や結びつきをDataviewで自動追跡するためのプロパティ定義です。

YAML

```
---
id: "idea-20260912-001"
title: "着想の名称（動詞＋目的語の短文）"
category: "アイデア・着想"
type: "fleeting"               # fleeting (断片) / developing (熟成中) / matured (企画化)
status: "inbox"                # inbox / incubated / linked / archived
confidence: 3                  # 直感の確信度・有望度 (1-5)
feasibility: 4                 # 実現容易性 (1-5)
domain:
  - "不動産DX"                 # 適用ドメイン（複数選択可）
  - "AIエージェント"
origin_trigger: "日常業務の課題" # 着想源 (業務課題 / 読書 / 他業種アナロジー / 雑談)
related_mocs:
  - "[[MOC_業務自動化]]"
created: 2026-09-12 17:35
updated: 2026-09-12 17:35
---
```

### 3. タグ・リンク設計（着想ネットワークの結合ルール）

- **ステータスタグ（進捗の可視化）**
    
    - `#idea/seed`: 思いつき・走り書き（未整理）
        
    - `#idea/nurturing`: 関連情報・派生ノートを追記して壁打ち中
        
    - `#idea/crystallized`: 具体的な仕様・プロジェクトへ昇華済み
        
- **思考トリガー・着想法タグ（発想法の分類）**
    
    - `#method/scamper`: 代替・結合・転用による発想
        
    - `#method/analogy`: 異業種・自然界からのアナロジー思考
        
    - `#method/inversion`: 逆転の発想（あえて逆をやる）
        
- **双方向リンク規約（ネットワーク接続）**
    
    - **上流リンク**: なぜこのアイデアが生まれたか（`[[課題_内見案内コスト高騰]]` など）
        
    - **下流リンク**: どこに適用できるか（`[[No.160_戦略SWOT分析ジェネレーター]]` など）
        

### 4. Dataviewによる未接続アイデア抽出クエリ

着想ノートのうち、「他のノートとリンクしておらず孤立しているアイデア」や「一定期間放置されているシード」を自動収集するダッシュボード用コードです。

コード スニペット

```
TABLE
  confidence AS 有望度,
  feasibility AS 実現性,
  domain AS ドメイン,
  file.mtime AS 更新日
FROM #idea/seed
WHERE length(file.outlinks) <= 1
SORT confidence DESC, file.mtime DESC
```
