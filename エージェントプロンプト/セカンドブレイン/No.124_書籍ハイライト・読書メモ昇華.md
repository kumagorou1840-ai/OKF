### 3. ネスト型タグ設計（文脈・状態の動的トラッキング）

タグは単語の羅列ではなく、プレフィックスを用いた階層型タグ（ネストタグ）で統一します。

- **種別・情報ソース（Type）**
    
    - `#source/book`（書籍）
        
    - `#source/article`（Web記事）
        
    - `#source/audio`（オーディオブック・音声講義）
        
- **思考の昇華ステータス（Lifecycle）**
    
    - `#status/inbox`（ハイライト取り込み直後・未整理）
        
    - `#status/extracting`（要約・ボールド処理中）
        
    - `#status/crystallized`（永久ノート化済み・完了）
        
- **実務・適用先（Application）**
    
    - `#action/prompt`（エージェントプロンプトへの転用候補）
        
    - `#action/biz-model`（事業モデル・企画アイデア）
        
    - `#action/workflow`（業務フロー・自動化改善）
        

### 4. タグ × プロパティ × リンクの役割分担ルール

重複や管理の破綻を防ぐため、役割を厳格に切り分けます。

|**ツール**|**担当領域**|**具体例**|**目的**|
|---|---|---|---|
|**フォルダ**|物理的な所在・状態|`01_Sources/Books`|ノートの保管場所|
|**YAMLプロパティ**|定量・固定属性|`domain`, `rating`, `format`|Dataviewでの表形式集計・ソート|
|**タグ (`#...`)**|状態・アクション|`#status/inbox`, `#action/prompt`|未着手タスクの検索・抽出|
|**内部リンク (`[[...]]`)**|概念同士の結びつき|`[[意思決定プロセス]]`, `[[SWOT分析]]`|知識グラフ（Graph View）の形成|

### 5. Dataviewによる未処理メモの自動回収クエリ

「本を読んでハイライトを入れたが、永久ノートに昇華できていない」ノートを一覧化するダッシュボード用コードです。

コード スニペット

```
TABLE 
  domain AS 分野,
  file.mtime AS 最終更新日
FROM #source/book
WHERE processed = false AND contains(file.tags, "#status/inbox")
SORT file.mtime DESC
```
