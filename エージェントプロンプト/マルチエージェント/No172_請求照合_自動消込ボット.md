## 2. アーキテクチャ・ダイアグラム

```python
from fuzzywuzzy import fuzz

def match_payment(bank_transfer, invoices):
    for inv in invoices:
        score = fuzz.ratio(bank_transfer.payer_name, inv.customer_name)
        if score > 85 and bank_transfer.amount == inv.billed_amount:
            return inv # マッチング成功
```
