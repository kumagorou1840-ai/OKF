## 2. アーキテクチャ・ダイアグラム

```python
def apply_promotion_rules(cart, rules):
    # ルール優先度順に適用し重複割引を防止
    sorted_rules = sorted(rules, key=lambda r: r.priority)
    for rule in sorted_rules:
        if rule.is_eligible(cart):
            cart = rule.apply(cart)
    return cart
```
