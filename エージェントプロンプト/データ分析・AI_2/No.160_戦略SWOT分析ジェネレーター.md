## 2. スキル連携手順書（実装・実行パイプライン）

コード スニペット

```
flowchart LR
    A[SQLite] -->|構造化データ・履歴管理| B[DecideFlow]
    B -->|戦略推論・クロス判定| C[ml-plotly-dash-helper]
    C -->|チャート・スコア生成| D[HTML5]
    D -->|ダッシュボードUIレンダリング| E[成果物完成]
```

### Step 1: SQLite（データ設計・永続化）

- **テーブル設計**:
    
    - `swot_items`: 要素ID、カテゴリ（S/W/O/T）、内容テキスト、重み付けスコア（1〜5）。
        
    - `cross_strategies`: 戦略ID、タイプ（SO/WO/ST/WT）、戦略名称、アクション詳細。
        
    - `strategy_eval`: 評価スコア（インパクト、実現性、リソース消費）。
        
- **役割**: 入力データと分析結果をローカルDBに保存し、案件ごとの復元・比較を可能にする。
    

### Step 2: DecideFlow（論理決定・クロス戦略推論）

- **処理ロジック**:
    
    - S・W・O・Tのカードから意味的関連性を総当たり判定。
        
    - `S × O`（積極攻勢）、`W × O`（弱点克服）、`S × T`（差別化）、`W × T`（防衛・撤退）の4マトリクスへ論理的に自動マッピング。
        
- **出力**: 矛盾や重複のない実行可能アクションプラン候補。
    

### Step 3: ml-plotly-dash-helper（可視化・定量評価エンジン）

- **処理ロジック**:
    
    - DecideFlowが算出したスコアからPlotly描画用コード（JavaScript/Python）を動的生成。
        
    - ダークテーマ（高コントラスト設計）の配色ルールを自動適用。
        
- **出力**: レーダーチャートおよび優先度バブルチャートのコンポーネント。
    

### Step 4: HTML5（スタンドアロンWebダッシュボード出力）

- **構成**:
    
    - 単一HTMLファイル（HTML5 + Tailwind CSS + Plotly.js）。
        
    - ブラウザで開くだけで即座に動作する完全完結型シングルページアプリケーション。

    ### 1. 現状の問題点・課題点の整理

ダミー業務実績データから抽出されたボトルネックは以下の3点です。

- **集客のポータル依存とコスト高騰**
    
    自社Web経由の成約比率が**11.2%**（目標ベンチマーク35.0%）と低迷しており、大手ポータルへの掲載料上昇（**+18.0%**）が利益を直接圧迫しています。
    
- **労働集約的な業務体質と残業過多**
    
    1人あたりの月間残業時間が**38.5時間**（適正値20.0時間）に達しており、属人的な賃貸仲介業務・内見案内が社員の負荷となっています。
    
- **人口減少エリアにおける管理資産の収益格差**
    
    生産年齢人口の減少（**-2.4%**）が進む中、郊外の不採算管理物件が増加し、地場トップシェア（**32.5%**）の利益率を相殺しています。

### 3. 今後の見通し・効果効率のシミュレーション

`ml-plotly-dash-helper` によるスコアリングと効果試算は以下の通りです。

```
【期待収益インパクト】
高 ↑
   │  [SO: 空き家再生 (9.2)] ★高収益・主力化
   │  [ST: プレミアム物件 (8.8)]
   │  [SO: オーナーメディア (8.4)] ★即着手推奨 (Quick Win)
   │  [WO: 仲介自動化Bot (7.5)]
   │  [WT: 不採算統廃合 (5.0)]
低 ┼────────────────────────────────────→ 
   低(容易)                高(困難) 【実行難易度】
```

#### 費用対効果（ROI）と改善インパクト

- **最優先着手（Quick Win）**: `オーナー向けメディア` & `不採算エリア統廃合`
    
    - 実行難易度が低く（2.5〜3.8）、総予算500万円以内で着手可能。残業時間の即時抑制（約-10時間/月）と固定費圧縮を短期間で達成します。
        
- **主力収益化（Strategic Win）**: `空き家再生宿泊施設`
    
    - 予算800万円・難易度4.5と一定の投資を要しますが、期待収益スコアは最高峰の**9.2**。遊休資産の利回り化により、管理料以外の第2の収益柱を確立します。
        
- **業務効率化**:
    
    - 仲介自動化Botの導入により、年間約**220時間/人**の業務工数を削減。削減されたリソースを空き家再生や個別提案営業などの高付加価値業務へシフト可能です。
