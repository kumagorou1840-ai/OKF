## 2. Mermaid ダイアグラム

```mermaid
flowchart LR
    Cron[夜間バッチトリガー] --> FetchInvoices[未消込請求書取得]
    Cron --> FetchBank[銀行振込明細データ取得]

    FetchBank --> FuzzyMatch
    FuzzyMatch -- スコア >= 85% --> AutoClear[自動消込実行 (payments 登録)]
    FuzzyMatch -- スコア < 85% --> ManualList[手動確認リストへ抽出]
```
