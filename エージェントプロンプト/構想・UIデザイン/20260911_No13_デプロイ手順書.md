# 📦 No.13 環境構築・デプロイメント手順書

## 1. 概要

本ドキュメントは、Windows環境においてAIエージェント自動化システムをゼロからセットアップし、Obsidian Vaultとの連携を起動するまでの**ステップ・バイ・ステップ手順**を記載します。

---

## 2. 前提環境要件 (Prerequisites)

- **OS**: Windows 11 / 10 (PowerShell 7.x 推奨)
- **Python**: 3.10 以上 (Virtualenv 推奨)
- **Node.js**: v20.x / v24.x 以上 (Obsidian プラグイン / フック用)
- **Git**: 2.40 以上 (`git worktree` サポート)
- **Obsidian**: 最新版 (Dataview / Mermaid 有効化)

---

## 3. セットアップ・デプロイ手順

### Step 1: リポジトリのクローンと仮想環境の作成
```powershell
# 1. ワークスペースフォルダへ移動
cd C:\Users\PC_User\Forge

# 2. Python 仮想環境の生成と有効化
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 3. 依存ライブラリの一括インストール
pip install pandas plotly pydantic fastapi uvicorn pytest
```

### Step 2: フォルダ構造の初期化
```powershell
# Obsidian Vault 内の出力先フォルダを生成
$targetDir = "C:\Users\PC_User\Obsidian\obsidian_1\エージェントプロンプト\構想・UIデザイン"
if (-not (Test-Path $targetDir)) {
    New-Item -ItemType Directory -Path $targetDir -Force
}
```

### Step 3: API サーバー＆ダッシュボードの起動
```powershell
# バックエンドエージェント API サーバーの起動
uvicorn src.interfaces.api.main:app --reload --port 8000
```

---

## 4. ヘルスチェックと動作確認 (Health Check)

```powershell
# API の健全性確認
Invoke-RestMethod -Uri "http://localhost:8000/healthcheck" -Method Get
# 期待出力: @{ status = "ok"; service = "agent-orchestrator" }
```
