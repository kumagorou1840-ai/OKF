# 🔌 No.6 API・入出力仕様定義書

## 1. 概要

本ドキュメントは、Obsidian GUIダッシュボードおよびWebコンソールから、バックエンドの Antigravity エージェントエンジンを操作・監視するためのRESTful APIおよびWebSocketストリーミングメッセージ仕様を定義します。

---

## 2. API エンドポイント一覧

| メソッド | エンドポイント | 概要 | 通信方式 |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/v1/pipeline/start` | 新規パイプラインセッションの開始 | REST / JSON |
| `POST` | `/api/v1/autonomy/level` | AI自律度レベル（1〜3）のリアルタイム変更 | REST / JSON |
| `POST` | `/api/v1/decision/approve` | 人間（よっちゃん）によるフェーズ承認 / 差戻し | REST / JSON |
| `GET` | `/api/v1/pipeline/{run_id}` | パイプライン全体ステータスの取得 | REST / JSON |
| `WS` | `/ws/v1/agent/logs` | エージェントの思考・ツール実行リアルタイムストリーム | WebSocket |

---

## 3. 入出力詳細仕様（JSON Schema & Payload）

### 3.1 パイプライン開始 API
- **Endpoint**: `POST /api/v1/pipeline/start`
- **Request Body**:
```json
{
  "project_path": "C:\\Users\\PC_User\\Forge",
  "input_prompt": "物件の空室対策アイデアの分析とObsidianノート生成",
  "autonomy_level": 2,
  "target_obsidian_dir": "C:\\Users\\PC_User\\Obsidian\\obsidian_1\\エージェントプロンプト\\構想・UIデザイン"
}
```
- **Response Body (200 OK)**:
```json
{
  "status": "success",
  "run_id": "b6bc82a0-16dd-4a6b-b544-8ae61c7c7ac0",
  "initial_step": "REQUIREMENTS_DEFINITION",
  "created_at": "2026-09-11T07:24:00Z"
}
```

---

### 3.2 意思決定承認 API
- **Endpoint**: `POST /api/v1/decision/approve`
- **Request Body**:
```json
{
  "run_id": "b6bc82a0-16dd-4a6b-b544-8ae61c7c7ac0",
  "step_id": "step-req-01",
  "decision": "APPROVED",
  "feedback_comment": "この構成で問題なし。実装に進んでください。"
}
```
- **Response Body (200 OK)**:
```json
{
  "status": "acknowledged",
  "next_step": "SURGICAL_IMPLEMENTATION"
}
```

---

### 3.3 WebSocket リアルタイムログストリーム
- **Endpoint**: `WS /ws/v1/agent/logs?run_id=b6bc82a0-16dd-4a6b-b544-8ae61c7c7ac0`
- **Event Payload (Server -> Client)**:
```json
{
  "event_type": "TOOL_EXECUTION",
  "agent_role": "SURGICAL_CODER",
  "tool_name": "replace_file_content",
  "details": {
    "target_file": "src/components/Dashboard.tsx",
    "status": "SUCCESS",
    "diff": "+ const autonomy = 'semi-autonomous';"
  },
  "timestamp": "2026-09-11T07:24:05Z"
}
```
