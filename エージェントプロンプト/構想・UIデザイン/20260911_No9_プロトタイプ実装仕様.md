## 2. コーディング規約 (Coding Conventions)

1. **Python**: Type Hints (PEP 484) の全関数付与必須。Pydantic v2 によるデータ検証。
2. **TypeScript / React**: Strict Mode 有効化。無用な `any` 型の禁止。
3. **Surgical Editing Constraint**: ファイルを編集する際は必ず範囲指定（`StartLine`, `EndLine`）に基づく差分適用関数を使用。

### 3.2 Git Worktree 隔離実行スクリプト (Python)

```python
import subprocess
import os

def create_isolated_worktree(repo_path: str, branch_name: str) -> str:
    """エージェント作業用の孤立Git Worktree環境を即座に作成する"""
    worktree_dir = os.path.join(repo_path, ".worktrees", branch_name)
    os.makedirs(os.path.dirname(worktree_dir), exist_ok=True)
    
    cmd = ["git", "worktree", "add", "-b", branch_name, worktree_dir, "HEAD"]
    result = subprocess.run(cmd, cwd=repo_path, capture_output=True, text=True)
    
    if result.returncode != 0:
        raise RuntimeError(f"Worktree作成失敗: {result.stderr}")
        
    return worktree_dir
```
