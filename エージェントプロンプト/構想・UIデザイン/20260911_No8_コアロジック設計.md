## 3. Surgical Changes (外科的改変) 制御アルゴリズム

AIエージェントが既存コードを変更する際、無関係な行の改変（空白・フォーマット変更・過剰なリファクタリング）を自動検出して拒否・再生成させる保護アルゴリズムです。

### 3.1 差分許容率判定疑似コード (Python)

```python
def validate_surgical_diff(original_code: str, modified_code: str, target_lines: range) -> bool:
    """
    指定されたターゲット行範囲外のコードが1文字でも変更されている場合、
    Karpathy Surgical Changes ルール違反としてエラーを発生させる。
    """
    orig_lines = original_code.splitlines()
    mod_lines = modified_code.splitlines()
    
    # 行数の著しい増加・全置き換えをブロック
    if abs(len(mod_lines) - len(orig_lines)) > len(target_lines) * 2:
        raise SurgicalViolationError("許容範囲を超える行数の変更が検出されました（全書き換えの疑い）。")
    
    # ターゲット行範囲外の完全一致チェック
    for idx, (orig, mod) in enumerate(zip(orig_lines, mod_lines)):
        if idx not in target_lines and orig != mod:
            raise SurgicalViolationError(f"Line {idx+1} は変更対象外ですが改変されています: '{orig}' -> '{mod}'")
            
    return True
```
