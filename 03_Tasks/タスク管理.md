### 日付を設定する

Tasksには6種類の日付があります。よく使うのはこの3つ。

絵文字 意味 使いどころ  
📅 → 期限（Due）：いつまでに終わらせるか  
⏳ → 予定日（Scheduled）：いつ取り掛かるか  
🛫 → 開始日（Start）：いつから着手可能か例えばこう書きます:

```
- [ ] クライアントへ見積書送付 📅 2026-05-01 ⏳ 2026-04-29 🔼
```

copy

→ 「4月29日に取り掛かって、5月1日までに完了」というタスクです。

### 優先度をつける

絵文字1つで優先度が決まります。

書き方 意味  
⏫ → 最優先。他を止めてでもやる  
🔼 → 高め。今日〜明日中に  
（何もなし）→ 普通  
🔽 → 急がない

## 繰り返しタスクを設定する

**個人的に、これが一番便利だと思っている機能です。**

```
- [ ] 週次振り返り 🔁 every sunday 📅 2026-05-04
```

copy

これで毎週日曜日に「週次振り返り」タスクが自動で湧いてきます。完了するとその瞬間に次の日曜日の分が生成されます。一度設定したら、もう忘れることがない。

**使える繰り返しパターン:**

書き方→ 意味  
🔁 every day → 毎日  
🔁 every weekday → 平日のみ  
🔁 every friday → 毎週金曜  
🔁 every 2 weeks → 2週間ごと  
🔁 every month on the 15th → 毎月15日  
🔁 every month on the last day → 月末

ゴミ出し、月次レポート、定例会議、習慣トラッカー。**全部これで自動化できます。** 外部アプリ不要。

## タスクダッシュボードを作る

[[タスク一覧]]


ここがTasksの真骨頂。**ノートに散らばったタスクを、1つの画面に自動で集める**機能です。

任意のノート（たとえば「ダッシュボード.md」）に、以下のコードブロックを書いてください。

```
not done
due before tomorrow
sort by priority
```

copy

（※ これを tasks コードブロックの中に書きます）

これだけで、**Vault内の全ノートから、明日までに期限が来る未完了タスクを、優先度順で一覧表示**します。

[![画像](https://assets.st-note.com/img/1777435701-LaYbfiMH4WqucGRKdFk8jTZS.jpg?width=1200)](https://assets.st-note.com/img/1777435701-LaYbfiMH4WqucGRKdFk8jTZS.jpg?width=2000&height=2000&fit=bounds&quality=85)

**しかも、この一覧からチェックを入れると、元のノートのタスクも自動で完了になります。** 元のノートを開きに行く必要がない。これが本当に便利。

### コピペで使えるクエリ集

**今日のタスク:**

```
not done
due today
sort by priority
```

copy

**今週のタスク（案件ごとにグループ化）:**

```
not done
due this week
sort by due
group by folder
```

copy

**期限切れタスク（ヤバいやつ）:**

```
not done
due before today
sort by due
```

copy

## まとめ

Tasksプラグインを入れると、Obsidianのチェックボックスが「本物のタスク管理ツール」に変わります。

- **期限・優先度・繰り返し**をタスクに設定できる
    
- **全ノートからタスクを自動収集**してダッシュボードに表示
    
- **繰り返しタスク**で習慣管理やルーティンワークを自動化
    
- 外部タスクアプリが不要になる
    

インストール2分。設定10分。世界が変わります。
