2. 真に「AIに考えさせる」ための解決アプローチ（方・移・拡・新）



本当にAIに考えさせるためには、「Pythonサーバー側に Gemini API を組み込み、リアルタイムで推論結果をブラウザに返す」という仕組みを実装します。

graph LR User[よっちゃん] -->|① お題「枕」を入力| Web[ブラウザ UI] Web -->|② お題 ＋ 技法プロンプトを送信| Py[Python サーバー] Note over Py: ③ プロンプト内の<br/>「〈対象を記入〉」を<br/>「枕」に自動置換 Py -->|④ APIキーを使ってリクエスト| Gemini[Gemini API / LLM] Gemini -->|⑤ 本気で推論したアイデア回答| Py Py -->|⑥ 回答データを返却| Web Web -->|⑦ タイピングアニメーションで表示| User

具体的な処理の流れ：


1. プレースホルダーの自動置換：
よっちゃんが右下の入力欄にお題（例：枕）を入力して送信します。
アプリ側が、選択されている技法の指示文（例：〈 アイデアを得たい対象を記入 〉を７つ考えてください）の中の 〈...〉 部分を自動で 枕 に置換し、完成されたプロンプトを作ります。
2. Gemini APIの呼び出し：
Pythonサーバー側で google-generativeai ライブラリを使用し、置換されたプロンプトをGemini（例：gemini-2.5-flash など）に送信します。
3. 推論回答の描画：
Geminiが本気で考えた回答をブラウザに返し、マークダウン形式でリアルタイムに画面に出力します。
