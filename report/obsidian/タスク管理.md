# タスク管理

以下は、動画の考え方を自分のObsidianで実践するためのToDoリストです。優先度は高・中・低で整理しています。

## 優先度: 高

- [ ] Obsidianの保存先を決め、作業用Vaultを整理する
- [ ] メモの命名ルールを決める（例: 日付_テーマ_内容.md）
- [ ] 1日1回の「インプット記録」を残すテンプレートを作る
- [ ] 重要な知識には「原理・背景・活用法」を書く構造を持たせる
- [ ] ノート間のリンクを意識して、関連メモを接続する
- [ ] AIに渡す前提として、要点・結論・根拠を分けて記録する
- [ ] 「自分の思考の棚卸し」を週1回実施する

## 優先度: 中

- [ ] 一つのテーマを1ノートにまとめる習慣を作る
- [ ] 自分の発想やアイデアを、最終的な用途に結びつけて記録する
- [ ] 検索しやすくするためにタグを統一する
- [ ] 過去のメモを見直し、重複・古い知識を整理する
- [ ] 既存のメモから新しい仮説や改善案を生む習慣を持つ
- [ ] AIへ依頼する際に、読み込ませる文脈を選ぶ

## 優先度: 低

- [ ] 知識の可視化のためにマインドマップやリンクグラフを活用する
- [ ] 定期的にシステムを見直し、ノート構造を改善する
- [ ] 自分専用のテンプレート集を充実させる
- [ ] メモの質を上げるために、定期レビューの文化を作る

## 実行ルール

- 1日1回、最低1つのメモを追加する
- 1週間に1回、関連ノートを横断して整理する
- AIに依頼する前に、自分の知識が自分の中で結びついているか確認する
