```markdown
# 不動産重要事項説明 チェックリスト

> 媒介・仲介業者が説明する事項を確認するためのリスト  
> 中古分譲物件（マンション・一戸建て）を中心に作成

## 〇 物件基本情報

- [ ] 物件の名称・所在地（住所・地番）
- [ ] 建物の構造（鉄筋コンクリート等）
- [ ] 延床面積・総戸数・築年数
- [ ] 予定価格または成約価格
- [ ] 用途（専有・用途指定内容）

## 〇 土地使用に関する事項

- [ ]  land 的地番・所在地
- [ ] 占有の有無と状況（借主・占有者の氏名・氏名）
- [ ] 賃貸借・借地等の関係

## 〇 建物に関する事項

- [ ] 構造、築年数、耐用年数
- [ ] 現況（占有の有無、賃貸借の実施）
- [ ] 修繕の状況と近几年的な修繕費

## 〇 賃貸借に関する事項

- [ ] 借主（入居者）の氏名及び居住者人数
- [ ] 家賃・管理費等の金額及び負担
- [ ] 契約期間・更新条件・違約金の説明

## 〇 修繕積立金等に関する事項

- [ ] 修繕積立金の現在の貯蓄状況
- [ ] 前年・前々年の積立状況（決算実績）
- [ ] 管理費（月額）・管理会社名
- [ ] 管理・会計・事業の内容

## 〇 管理組合に関する事項

- [ ] 管理組合の名称・所在地・設立日
- [ ] 法人格の有無・役員名簿・定款
- [ ] 規約・議事録・決議事項の内容
- [ ] 管理の委任契約・管理手数料の金額
- [ ] 準則・特別決議の内容

## 〇 抵当権等（担保）に関する事項

- [ ] 抵当権の設定状況・設定限度額
- [ ] 債務残高の状況（未払の有無）
- [ ] 特定抵当権の有無・共有者・占有者の情報

## 〇 その他の確認事項

- [ ] 瑕疵担保に関する説明（構造・設備のトラブル歴）
- [ ] 都市計画・建築規制に係る事項
- [ ] 取引の目的及び条件（費用負担の划分）
- [ ] 説明を受けた確認（当事者の理解）

## 〇 説明記録

- [ ] 説明日付・対象物件番号
- [ ] 説明を受けた者（購入者・代理人）の氏名
- [ ] 添付資料（定款・規約・決算書等）のリスト
```

**補足ポイント**

- このリストは、日本における「不動産媒介・仲介」で法律上説明すべき事項を網羅する目安として、主要項目を簡潔にまとめたものです。
- 実際の取引では、物件の規模に応じて項目を増減させる必要がございます。
- 保存の際は、ノートトップに `#タグ` を付与し、関連ノートとリンクすることをおすすめします。
